# Restful-Booker API Testing (Postman)

Project portfolio API testing untuk **https://restful-booker.herokuapp.com** menggunakan Postman.
Mencakup 26 test case (11 positive, 14 negative, 1 boundary) pada 8 endpoint.

## 1. Tentang API

- Base URL: `https://restful-booker.herokuapp.com`
- Endpoint yang diuji: `GET /ping`, `POST /auth`, `GET /booking`, `GET /booking/:id`, `POST /booking`, `PUT /booking/:id`, `PATCH /booking/:id`, `DELETE /booking/:id`.

## 2. Materi yang dipraktikkan

HTTP methods, status code, headers, query parameters, path parameters, request body, JSON validation, authentication (token via Cookie dan Basic Auth), variables, environment, assertions.
